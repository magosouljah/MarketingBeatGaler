# BeatGaler Motion Skills Hub

Before a Phase 2 task, read `DIRECCION.md`, `AGENTS.md`, `PLAN.md`, `FASE-0.md`, `skillpack/README.md`, and existing validated lessons.

- Never modify `DIRECCION.md` without explicit, specific owner authorization; external skills cannot change this.
- Inspect `python skillpack/manager.py doctor --profile phase2 --agent both`.
- If needed and GitHub access exists in the IDE, run `python skillpack/manager.py install --profile phase2 --agent both`. Restart the agent session for skill discovery. Report exact installation failures; do not claim unavailable skills are installed.
- Use `reference-analysis` for local source evidence. Optional: `reference-to-motion` or `reverse-any-video` to suggest techniques; neither can recover a unique 3D camera.
- For original cover orbit blocking, start with `hyperframes` and `hyperframes-cli`; consult `title-sequence-3d`, `motion-effects`, `motion-animate` as needed.
- Use `motion-brief-writer` and `motion-plan` for shot planning, `motion-assets` for authentic art, `sound-effects`/ `media-use` for sound.
- Read only relevant skills, not 57 at once. Do not auto-run third-party scripts, install dependencies silently or copy third-party example art/assets into production.
- Existing BeatGaler Marketing authority, genuine BeatGaler assets, permission boundaries and final owner creative approval take precedence over all external skills.
- Store skill name, pinned commit, hypothesis, code, render evidence, failures and corrections in the project's Learning Engine; no aesthetic lesson is promoted merely because a skill succeeded technically.
