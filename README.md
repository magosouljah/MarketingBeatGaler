# MarketingBeatGaler

**Sistema único de marketing de BeatGaler:** investigación → razonamiento → hooks/guiones → producción → medición → aprendizaje. El objetivo es obtener alcance entre productores musicales y visitas a BeatGaler. Los registros históricos no son resultados reales de audiencia.

## Mapa vigente

| Carpeta | Responsabilidad |
|---|---|
| [content/](content/README.md) | **Todos los videos, hooks, guiones, referencias y recursos creativos**, sin dividir por cuentas |
| [research/](research/psychology/README.md) | Fuentes originales, psicología, producto y Mapa de Deseos V3. Desde 2026-11-24 incluye la [biblioteca de conocimiento](research/biblioteca/README.md): mapa bibliográfico, fichas de fuentes leídas y principios sintetizados (comunicación y sabiduría para productores) |
| [pipeline/](pipeline/README.md) | Seis módulos de investigación a aprendizaje; [BeatGaler Hooks](pipeline/hooks/SKILL.md) es la skill creativa activa; [Formula Hooks](pipeline/formula-hooks/README.md) queda como laboratorio histórico |
| [learning/](learning/README.md) | Evaluaciones, casos, propuestas y lecciones de ejecución de producción |
| [shared/](shared/README.md) | Utilidades de edición, HyperFrames, FFmpeg, análisis de referencias y render |
| [skillpack/](skillpack/README.md) y [skills/](skills/reference-analysis/SKILL.md) | Skills reutilizables y dependencias externas verificadas |

## Instrucciones

- [AGENTS.md](AGENTS.md) es obligatorio para agentes. Leer reglas de producción de `learning/`; para hooks, usar [BeatGaler Hooks](pipeline/hooks/SKILL.md) (sin fórmula obligatoria). El [método B](pipeline/formula-hooks/REGLA.md) se consulta solo para experimentos históricos explícitos.
- [DIRECCION.md](DIRECCION.md) es un archivo rector **protegido**. No editarlo sin autorización específica. [PLAN.md](PLAN.md) y [FASE-0.md](FASE-0.md) conservan la historia del diseño de dos cuentas; la **estructura operativa actual** es `content/`, unificada por decisión del propietario del 2026-11-22.
- **No crear ramas ni PR.** Trabajar y versionar únicamente en `main`. No modificar producción de BeatGaler.
- Antes de commitear ejecutar el audit y los tests pertinentes. No presentar tests no ejecutados como aprobados.

## Evidencia y privacidad

`learning/` conserva identificadores históricos de cuenta para no alterar aprobaciones. En `content/research/reference-analysis/` los bytes de evidencia y sus hashes son intocables. No subir material privado del propietario ni MP4s no autorizados. La carpeta temporal `pipeline/formula-hooks/temporal-diagnostico-3-pasos/` se conserva hasta que el propietario solicite borrarla.
