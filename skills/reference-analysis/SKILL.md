# Reference Analysis

Work from the MarketingBeatGaler repository root. Read DIRECCION.md, AGENTS.md, the brief, reference inventory, and validated lessons for the target account. DIRECCION.md and its protections must remain untouched. BeatGaler application assets are read-only.

Use [the execution guide](../../shared/reference_analysis/README.md) for CLI commands and contracts; use [research and decisions](../../shared/reference_analysis/RESEARCH.md) for methods, tool boundaries and sources.

## Evidence first

Confirm the local original exists. A link or historical report is not current video access. Record which material was actually examined. If missing, run the synthetic demo and document the blocked source-specific analysis. Do not substitute demo measurements for reference results.

Run the bounded full-frame extraction; inspect report warnings and the entire consecutive frame sequence, then watch the source in motion where playback is available. A contact sheet alone cannot validate temporal continuity. For clips beyond limits, request an explicit budget increase or separately prepared segments retaining original PTS offsets; do not silently drop frames. There is no fixed half-second sampling.

## Produce a useful technical breakdown

Separate pixel/PTS measurements from estimates, artistic interpretations and hypotheses. Automatic cut candidates are estimates. Split complex choreography into independent element translation, scale, visible rotation, overlap, occlusion and apparent depth, plus separate camera hypotheses. Annotate evidence frame ranges, method and uncertainty. Track visible anchors in normalized coded-image coordinates; split tracks at cuts, identity loss or occlusion. Never interpolate hidden geometry as observed fact. Velocity and acceleration are finite-difference estimates, not recovered easing functions.

Inspect timing/spacing, anticipation, arcs and overlapping action; composition/negative space; typography/readability; contrast/color; lighting/material/motion-blur interpretations; audio events and their visual alignment. State unexamined dimensions explicitly. Stream offsets do not establish lip sync or musical sync. Investigate unclear implementation using primary technical sources and record competing explanations and a discriminating test.

For the cover orbit, compare fan-out, relative scale/orientation, foreground crossings and exit continuity. Do not assert unique 3D camera coordinates, focal length, software or Z from a monocular clip. Test an original choreography as deterministic HyperFrames blocking; Three.js/GSAP or Blender are complementary only when justified. No full ad production in this workflow.

## Close the loop

Validate complete outputs before registering evidence. Register through the existing Learning Engine, preserving cases. For failures use `failure` with evidence, a cause hypothesis, implementation, use/avoid conditions and acceptance test. Classify the cause without claiming it is proven. Each candidate rule must identify problem, evidence, implementation, applicability, exclusions and verification. Prefer a new experiment to a new permanent rule.

Retain source hashes, provenance, analysis and diagnostics in versioned permitted evidence; keep third-party media and captures local unless redistribution is authorized. Create new case IDs for corrections. Never call `promote` without a distinct passing case and real owner approval. Technical tests and agent self-review do not grant creative approval.
