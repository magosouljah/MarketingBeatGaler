# BeatGaler Hooks
Al crear, revisar o mejorar hooks en MarketingBeatGaler, ejecuta el flujo de [pipeline/hooks/SKILL.md](../../../pipeline/hooks/SKILL.md). Lee sus principios, técnicas y criterio activos, y consulta el Mapa V3. Usa [pipeline/hooks/APRENDIZAJE.md](../../../pipeline/hooks/APRENDIZAJE.md) cuando el propietario evalúe el lote. No sustituyas el juicio creativo con una plantilla obligatoria ni afirmes que una propuesta tiene eficacia verificada.
