# Fichas de fuente

Una ficha por fuente **leída**. Las fuentes solo localizadas viven en [`../mapa/`](../mapa/).

## Plantilla

```
# F-0NN — Título — Autor (año)

| | |
| --- | --- |
| Edición usada | traductor, editorial, año; de dónde salió el texto |
| Biblioteca / área | A o B · área |
| Respaldo | etiqueta |
| Acceso | DIRECTA / EXTRACCION / RESUMEN — y qué partes exactamente |
| Principios que alimenta | K-… |

## Por qué merece atención
## Ideas fundamentales
(con capítulo o sección; sin números de página si la edición no los conserva)
## Lo que podemos aprovechar, y por qué funciona
## Aplicaciones posibles para productores (hipótesis nuestras)
## Límites, contradicciones y respaldo
## Qué falta leer de esta fuente
```
