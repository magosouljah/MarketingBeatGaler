# Shared — motor técnico común

Recursos reutilizables para ambas cuentas; **no contiene** gusto creativo, hooks, design guidelines ni feedback que puedan contaminar el perfil editorial de otra cuenta.

- `research/` — contrato de referencias y criterios para verificar outliers.
- `transcription/` — futura transcripción y timestamps.
- `editing/` — futura mecánica de montaje.
- `ffmpeg/` — futuros comandos y utilidades de edición.
- `hyperframes/` — futura integración con el renderer HyperFrames aprobado en Fase 0.
- `rendering/` — futura generación de previews y MP4.
- `technical-qa/` — futuras comprobaciones técnicas de video.
- `product-source-assets/` — material fuente verificable de la UI/producto.

Las carpetas marcadas con `.gitkeep` están reservadas; **no representan funcionalidad implementada**.
