| Option | What the source establishes | V1 decision / limitations |

| [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html) | Official filter reference (web fetch timed out); local `ffmpeg -h filter=scale` and actual extraction tests establish used filter support | Selected existing binary for downscaling, grayscale decode and PNG evidence. | [OpenCV optical flow](https://docs.opencv.org/4.13.0/d4/dee/tutorial_optical_flow.html) | Lucas–Kanade tracks features; Farnebäck estimates dense apparent 2D motion under assumptions | Defer automatic tracking until source available; texture loss, blur, occlusion and changing card faces can invalidate correspondence. | [OpenCV calibration](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html) | Projection depends on intrinsics, transforms and scale | Do not infer exact camera/3D from a monocular clip without constraints, correspondence and reprojection tests. |
| [Blender camera solve](https://docs.blender.org/manual/en/latest/animation/constraints/motion_tracking/camera_solver.html) | Marker tracking and solving precede reconstructed camera constraints | Potential complementary reconstruction test; independently animated cards on plain background are not a static rigid scene. | [IBM classic animation principles](https://www.ibm.com/design/language/animation/classic-principles/) | Timing, anticipation, follow-through and related principles inform motion design | Review rubric, not numerical measurements or universal aesthetic rules. ## Chosen pipeline and epistemic boundaries

1. Probe/check budgets before decode. All native presentation frames are included at reduced spatial resolution: appropriate to short, potentially fast motion without guessed temporal sampling. Do not claim sub-frame motion beyond source exposure/FPS.
2. Measure normalized luma and adjacent pixel difference on thumbnails. Estimate candidate cuts only. Preserve repeated pixels as valid evidence and flag, never automatically delete them.
3. Review entire sequence plus playback. Decompose each visible movement separately. Use source-frame annotations for observations/interpretations/hypotheses and optional manual 2D anchors for estimated normalized velocity/acceleration. Positional uncertainty propagates into derivatives; no hardcoded confidence scores. No smoothing or inferred hidden sections in V1.
4. Separate visible projection change from camera-motion hypothesis. Object rotation, dolly, zoom, scale and depth can produce ambiguous projected changes. Apparent occlusion ordering constrains relative depth only where visibility is unambiguous.
5. Inspect type, contrast, negative space, color, illumination/material cues, blur and sound manually. These are not implemented automated detectors. Offset warnings cover only stream start metadata; no semantic AV synchronization claim.
6. Research unfamiliar mechanisms, retain source citations, compare competing implementations. For reconstructed tests use deterministic evaluation by time and matching aspect ratio/time alignment. Compare tracked anchor reprojection errors and occlusion order, plus continuous playback. Pixel similarity alone penalizes original artwork and does not establish motion quality.
7. Register evidence/failure in existing Learning Engine; proposals include problem, evidence, method, use/avoid and acceptance tests. Do not create a parallel memory store or promote agent opinions as approved art.
