# Técnicas — caja de herramientas

No son una secuencia ni una plantilla. Seleccionar, combinar o descartar según la idea. Si una técnica no aporta algo a la experiencia concreta, no usarla.

| Técnica | Operación creativa |
| --- | --- |
| Progresión por consecuencias | Identificar lo que el hook ya consigue y avanzar hacia algo distinto que eleve el interés: tener el recurso pero no encontrarlo a tiempo, descubrir una oportunidad, mostrar una consecuencia o revelar cómo actuar. No repetir el problema con otros términos. |
| Escena imaginada | Hacer sentir una oportunidad, problema o descubrimiento plausible mediante una situación breve. Elegir una consecuencia relevante, no dramatizar por dramatizar. Varios guiones de pérdida imaginada fueron rechazados; no conocemos una causa única ni queda prohibida la técnica. |
| Evidencia real como desarrollo | Buscar casos concretos, reconocibles y pertinentes que hagan visible el riesgo o beneficio. Pueden aportar información interesante y sustituir una explicación hipotética. Verificar por separado personas, cifras, causas y alcance; no atribuir negligencia ni convertir anécdotas en estadísticas. Las historias aceptadas de pérdidas musicales deben conservar sus diferencias: fallo, inundación y robo. |
| Contraste de valor | Comparar lo fácilmente reemplazable con el trabajo creativo acumulado que no se puede simplemente volver a descargar. El contraste debe revelar una diferencia significativa; no basta cambiar la cifra o el objeto en una versión ya aceptada. Evitar afirmar que toda recuperación de datos es imposible. |
| Valor acumulado | Hacer que el productor reconozca qué está construyendo cada vez que termina un beat. Conectar esa perspectiva con una acción breve que proteja o aproveche lo construido. No inventar una valoración económica. |
| Experiencia propia | Usar lo que el propietario realmente hace, sabe o ha vivido para demostrar utilidad sin sermonear. En una situación práctica, explicar la decisión que toma y la ventaja que obtiene. No inventar anécdotas, ingresos ni resultados. |
| Beneficio convertido en acción | Pasar de una actividad abstracta a un uso que tenga sentido: identificar un material valioso, explicar qué hacer con él y hacer imaginable un resultado. En tutoriales de beats antiguos, una melodía rescatada puede servir de sample propio o conservarse mientras se reconstruyen drums y mezcla. Transferir el mecanismo, no reciclar el tema. Comprobar requisitos como disponer de los stems/proyecto. |
| Cierre que anticipa | Cuando el guion enseña una acción, cerrar haciendo que el espectador visualice el resultado en vez de añadir un consejo genérico. El cambio del propietario de «You might turn» a «Watch yourself turn» es evidencia de preferencia de expresión, no autorización para garantizar resultados. Un cierre emocional breve puede funcionar mejor cuando el valor ya se ha demostrado. |
| Eliminación por función | Leer en voz alta y quitar una frase. Si no se pierde comprensión, interés, emoción, ritmo o una transición necesaria, puede sobrar. No recortar información esencial para alcanzar una duración arbitraria. |
| Integración visual | Mostrar una acción real de BeatGaler justo cuando la narración presenta la necesidad o solución. La narración puede seguir hablando del beneficio y la imagen mostrar cómo. Verificar las funciones actuales; no hacer una demostración decorativa. |
| Cambio de perspectiva y rescate | Ante un guion malo, separar contenido, conflicto, emoción, lenguaje y cierre. Conservar los componentes que el propietario rescata y construir nuevos desarrollos que los merezcan. Explorar mecanismos diferentes (competencia, valor práctico, evidencia, acumulación, creatividad) en vez de repetir una variante con nuevos sinónimos. No imponer una emoción inicial. |
| Variantes de un concepto | Probar enfoques narrativos o expresiones distintos alrededor de la misma enseñanza. Si el propietario permite cambiar el hook, explorar también esa dimensión y señalarlo. Para comparar una variable, mantener las demás razonablemente estables; para explorar creatividad, permitir más cambios y registrarlos. Reutilización audiovisual sigue siendo propuesta, no decisión de cantidad o calendario. |
