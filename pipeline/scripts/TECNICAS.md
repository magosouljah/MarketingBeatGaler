# Técnicas — caja de herramientas

No son una secuencia ni una plantilla. Seleccionar, combinar o descartar según la idea.

| Técnica | Operación creativa |
| --- | --- |
| Progresión por consecuencias | Partir del conflicto y descubrir qué perdería o ganaría el productor; avanzar a una consecuencia nueva, no a una reformulación. |
| Escena imaginada | Hacer sentir una oportunidad, problema o descubrimiento plausible mediante una situación breve y concreta. Si el hook ya la establece, no repetirla. |
| Cambio de perspectiva | Explorar qué otra emoción o consecuencia emerge del mismo contenido: oportunidad, competencia, pérdida, tranquilidad, dominio. No imponer una emoción inicial. |
| Experiencia propia | Usar lo que el propietario realmente hace, sabe o ha vivido para demostrar utilidad sin dar sermones. No inventar anécdotas, ingresos ni resultados. |
| Contraste de valor | Comparar qué se puede reemplazar fácilmente con aquello cuyo valor depende del trabajo creativo acumulado. Hacer visible una pérdida concreta, no solo repetir que sería triste perderla. Evitar afirmar que toda recuperación es imposible; precisar la ausencia de una copia recuperable cuando importe. |
| Eliminación por función | Leer el guion en voz alta, quitar una frase y comprobar si se pierde comprensión, interés, emoción o ritmo. Si nada se pierde, puede sobrar. |
| Integración visual | Mostrar una acción real de BeatGaler justo cuando la narración presenta la necesidad o solución. La narración puede seguir hablando del beneficio y la imagen mostrar cómo. |
| Variantes de un concepto | Probar enfoques narrativos o expresiones distintos alrededor de la misma enseñanza. Cuando se quiera comparar una variable, mantener las demás razonablemente estables; cuando se quiera explorar creatividad, permitir más cambios y registrarlos. |
