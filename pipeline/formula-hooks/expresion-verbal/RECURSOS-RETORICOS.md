# Recursos retóricos

**Operaciones que aplicamos al lenguaje para comunicar una idea.** Se conserva la **última tabla enviada**, sin sustituirla por versiones anteriores.

| Categoría | Recursos |
| --- | --- |
| **Comparación y significado** | Metáfora, símil, analogía, alegoría, símbolo, metonimia, sinécdoque, personificación, antonomasia, perífrasis, sinestesia, alusión, catacresis. |
| **Oposición** | Antítesis, paradoja, oxímoron, ironía, sarcasmo, antífrasis, concesión, corrección retórica, contraste. |
| **Intensificación** | Hipérbole, lítote, amplificación, gradación, clímax, anticlímax, acumulación, enumeración, exageración deliberada, atenuación. |
| **Repetición** | Anáfora, epífora, anadiplosis, epanadiplosis, epizeuxis, complexión, conduplicación, poliptoton, paralelismo, isocolon, quiasmo, antimetábole. |
| **Interpelación y razonamiento** | Interrogación retórica, hipófora, procatalepsis, apóstrofe, dialogismo, aporía, entimema, dilema, argumento por analogía, reducción al absurdo. |
| **Omisión y orden** | Elipsis, asíndeton, polisíndeton, zeugma, silepsis, anacoluto, hipérbaton, anástrofe, histéresis, aposiopesis, reticencia, paréntesis, parataxis. |
| **Sonido y ritmo** | Aliteración, asonancia, consonancia, onomatopeya, rima interna, homoioteleuton, eufonía, cacofonía, ritmo verbal. |
| **Juegos de lenguaje** | Paronomasia, calambur, dilogía, equívoco, retruécano, doble sentido, parodia, juego de palabras, aforismo, epigrama. |
| **Descripción y representación** | Hipotiposis, écfrasis, descripción sensorial, ejemplificación, prosopografía, etopeya, topografía. |

Incluye equivalencias, subtipos y estrategias prácticas; no se afirma que todos sean distintos o exhaustivos.
