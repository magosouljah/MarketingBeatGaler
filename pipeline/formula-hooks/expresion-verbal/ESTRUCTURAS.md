# Estructuras de comunicación

**Determinan cómo organizamos y presentamos la información.** Se conserva la **última tabla enviada**, sin sustituirla por versiones anteriores.

| Categoría | Estructuras |
| --- | --- |
| **Presentación directa** | Afirmación directa, pregunta directa, orden, advertencia, promesa, declaración provocadora, dato primero, conclusión primero. |
| **Pregunta y respuesta** | Pregunta → respuesta, problema → explicación, misterio → resolución, enigma → pista, pregunta → nueva pregunta, respuesta → justificación. |
| **Contraste** | A vs. B, antes vs. después, expectativa vs. realidad, creencia vs. evidencia, mito vs. realidad, no A ni B sino C, regla vs. excepción. |
| **Causa y consecuencia** | Causa → efecto, efecto → causa, acción → consecuencia, error → resultado, condición → resultado, decisión → consecuencias alternativas. |
| **Problema y solución** | Problema → solución, solución → problema, error → corrección, obstáculo → método, método antiguo → método nuevo, solución aparente → solución real. |
| **Demostración** | Resultado primero → proceso, predicción → prueba, hipótesis → experimento, comparación práctica, ejemplo → principio, principio → ejemplo. |
| **Narración** | Historia cronológica, empezar por el final, empezar en pleno conflicto, recuerdo del pasado, salto al futuro, transformación del protagonista, acontecimiento inesperado. |
| **Progresión** | Escalada, acumulación, cuenta regresiva, secuencia de pasos, lista creciente, revelaciones sucesivas, descubrimiento progresivo. |
| **Argumentación** | Tesis → evidencia, evidencia → conclusión, objeción → respuesta, contraargumento → refutación, analogía → conclusión, paradoja → explicación. |
| **Elección** | Dilema, dos alternativas, tres alternativas, comparación de riesgos, elección imposible, sacrificio necesario, negociación, decisión bajo presión. |

Son patrones posibles de ordenación de información; algunos coinciden con recursos retóricos.
