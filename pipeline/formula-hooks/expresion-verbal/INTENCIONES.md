# Intenciones comunicativas

**Qué queremos hacer con las palabras.** Biblioteca operativa basada libremente en familias de actos del habla, no una clasificación oficial cerrada.

| Categoría | Todas las posibilidades de la tabla acordada |
| --- | --- |
| **Informar** | Afirmar, comunicar, revelar, descubrir, explicar, describir, definir, aclarar, demostrar, confirmar, desmentir, actualizar. |
| **Investigar o cuestionar** | Preguntar, interrogar, cuestionar, desafiar, poner a prueba, comparar, examinar, confrontar, provocar reflexión. |
| **Persuadir** | Convencer, argumentar, refutar, recomendar, justificar, advertir, persuadir, disuadir, defender, denunciar. |
| **Orientar una acción** | Pedir, ordenar, sugerir, aconsejar, instruir, invitar, exigir, prohibir, animar, impulsar, retar. |
| **Comprometerse** | Prometer, garantizar, ofrecer, comprometerse, asegurar, anunciar una intención. |
| **Expresar o relacionarse** | Elogiar, admirar, agradecer, felicitar, criticar, reprochar, lamentar, disculparse, consolar, celebrar, reconocer, empatizar. |
| **Atraer y entretener** | Intrigar, sorprender, divertir, bromear, entusiasmar, inspirar, motivar, generar expectativa, despertar curiosidad. |

**Nota:** algunas intenciones son objetivos prácticos de comunicación y se solapan entre categorías.
