# Tonos

**Qué actitud transmite quien habla**, no necesariamente qué emoción sentirá el espectador.

| Categoría | Tonos |
| --- | --- |
| **Neutros y racionales** | Neutral, objetivo, informativo, analítico, científico, técnico, académico, didáctico, explicativo. |
| **Serios** | Serio, solemne, grave, sobrio, formal, profesional, autoritario, contundente. |
| **Intensos** | Urgente, alarmante, amenazante, provocador, desafiante, confrontativo, indignado, dramático. |
| **Misteriosos** | Enigmático, intrigante, inquietante, críptico, suspensivo, revelador. |
| **Humorísticos** | Cómico, juguetón, absurdo, irónico, sarcástico, satírico, burlón, irreverente, ingenioso. |
| **Cercanos** | Íntimo, conversacional, amistoso, empático, cálido, vulnerable, confesional, sincero, cómplice. |
| **Positivos** | Optimista, esperanzador, entusiasta, inspirador, motivador, celebratorio, admirativo. |
| **Negativos** | Pesimista, melancólico, nostálgico, triste, amargo, cínico, decepcionado, crítico. |
| **Expresivos** | Poético, filosófico, reflexivo, contemplativo, épico, cinematográfico, minimalista, informal, directo. |

Un tono puede coexistir con otros; estas categorías son agrupaciones de trabajo, no etiquetas excluyentes.
