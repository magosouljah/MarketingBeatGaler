# Expresión verbal — cuatro bibliotecas combinables

- [Intenciones](INTENCIONES.md): qué se quiere hacer al hablar.
- [Estructuras](ESTRUCTURAS.md): cómo se ordena la información.
- [Recursos retóricos](RECURSOS-RETORICOS.md): operaciones sobre lenguaje/significado.
- [Tonos](TONOS.md): actitud transmitida al hablar.

Las categorías **no son niveles sucesivos** ni mutuamente excluyentes. **Estructuras y recursos retóricos se solapan**: una paradoja o un dilema puede ser al mismo tiempo una operación verbal y la estructura completa. No imponer su uso simultáneo ni contar ese solapamiento como diversidad real.

Los contenidos de [Estructuras](ESTRUCTURAS.md) y [Recursos retóricos](RECURSOS-RETORICOS.md) reproducen **las últimas dos tablas acordadas**, no versiones anteriores. Intenciones y tonos conservan las categorías del catálogo previo.

**Estado:** catálogo de opciones para probar, no motor generativo implementado, lista exhaustiva académica ni garantía de retención.
