# E — Espectador

**Fuente canónica ya existente:** [Mapa de Deseos del Productor Musical V3](../../../research/psychology/sources/MAPA-DE-DESEOS-DEL-PRODUCTOR-V3.md). **No duplicar ni reescribir** ese documento: contiene el mapa extenso y sus referencias originales.

El componente espectador puede consultar y relacionar estas dimensiones; la nomenclatura X/I/D/M/V es una organización de trabajo nuestra, no la estructura literal del Mapa V3.

| Dimensión de E | Qué consultar en el Mapa V3 |
| --- | --- |
| **X · Experiencias** | Situaciones concretas, obstáculos, frustraciones, aprendizajes, experiencias pasadas. |
| **I · Identidad** | Autoconcepto, identidad artística, aspiraciones personales y profesionales. |
| **D · Deseos** | Necesidades profundas, resultados deseados, microdeseos, intereses. |
| **M · Miedos** | Amenazas percibidas, rechazo, fracaso, pérdida e incertidumbre. |
| **V · Valores** | Autonomía, competencia, relaciones, autenticidad, dignidad y significado. |
| **Creencias** | Interpretaciones, expectativas y convicciones del productor; explorarlas como hipótesis, no como opiniones de todos. |

**Fuentes adicionales del repositorio:** [investigación y notas](../../../research/psychology/README.md) y [evidencias del pipeline](../../1-investigacion/evidencia.csv).

**Criterio:** el Mapa V3 incluye investigación, hipótesis e inferencias; no se debe tratar una característica como universal ni como un testimonio específico sin comprobar su fuente. Las listas exploratorias de 210 elementos discutidas en el chat no se incorporan aquí como «210 testimonios verificados».

**Uso:** seleccionar una o varias características coherentes, conservando qué rasgo es fuente, qué es interpretación y qué es suposición.
