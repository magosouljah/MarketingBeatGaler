# Técnicas disponibles — herramientas, no receta

| Técnica | Uso |
| --- | --- |
| Foco y trayectoria de atención | Para cada unidad de sentido, identificar qué elemento mira el espectador y cómo pasa al siguiente. Coordinar cámara, movimiento, luz, escala y tipografía. No hacer competir dos protagonistas innecesariamente. |
| Mostrar la consecuencia | Convertir una situación verbal en una acción, comparación o resultado legible. En un beat antiguo, mostrar un antes/después audible si existen los recursos; no simular una prueba. |
| Acción con continuidad | Un objeto, cursor, gesto o transformación puede conectar escenas. Mantener su lógica espacial y temporal. No añadir movimiento arbitrario para rellenar. |
| Evidencia en pantalla | Utilizar entrevistas, noticias, citas o demostraciones verificadas en el momento pertinente. Respetar derechos de los assets; identificar las recreaciones. No crear capturas falsas de fuentes. |
| Interpretación de voz | Indicar intención por unidad de sentido, palabra de énfasis, pausa y cambio de energía. Probar lectura natural con el texto intacto; no pronunciar cada palabra como eslogan. Medir el audio grabado antes de cerrar tiempos. |
| Texto y legibilidad | Para tipografía cinética, mapear texto exacto → frase/palabra audible → posición/profundidad → entrada/salida y movimiento → política de repetición. Separar texto de interfaz, diálogo y tipografía editorial. Si hay lista cerrada, respetarla; si es flexible, justificar cambios relevantes. Evitar competir con la UI, mantener contraste y zonas seguras. |
| Beat, silencio y SFX | Usar golpes medidos, silencios o efectos con finalidad expresiva; distinguir la música de fondo de una demostración audible de producción. Ajustar niveles para voz inteligible sin ducking brusco. |
| Movimiento y descanso | Alternar actividad, continuidad, pausas y cambios de encuadre según lectura. Señalar las esperas con intención narrativa, duración aproximada y movimiento/sonido que mantiene el interés. Ejemplo contextual A-C1-H1: espera de typing con zoom lento antes de la respuesta. No adoptar los 0.8 s o 2 s de anuncios anteriores como límites generales. |
| Comparación de tratamientos | Cuando la apariencia de un objeto o escena decisiva no esté clara, proponer dos o tres alternativas en una imagen o animatic corto antes de animar todo. Es una propuesta de los videos previos, no una lección validada universal. |
| Diseño modular de versiones | Preparar apertura H1/H2/H3 y cuerpo C1/C2/C3 como unidades intercambiables. Definir punto de empalme, música y locución del cuerpo desde un origen local común. Probar continuidad con todas las aperturas; si una exige cambiar el cuerpo, señalarlo antes de romper el experimento. |
| Prueba del momento difícil | Prototipar primero la demostración, transición, tratamiento o gesto que más riesgo creativo tenga. No exigir un render entero para recibir feedback inicial. |
| Gestos de cámara decisivos | Especificar objeto de atención, dirección, motivación y momento de entrada/salida del movimiento; reservar detalle para zooms, cambios de foco y transiciones que alteren la lectura de la escena. |
| Inventario de producción | Identificar cada asset por nombre y función, fuente, estado, derechos y responsable de resolverlo. Entregar voces etiquetadas por lo que dicen, música seleccionada y referencias concretas si existen; si no, definir cómo obtenerlas y qué bloquean. |
| Contrato de libertad creativa | Separar instrucciones obligatorias, alternativas aceptables y decisiones delegadas. Para UI o funciones futuras, anotar estado real y quién diseña/autoriza la representación. Evitar reconstrucciones mediocres o promesas ficticias; validar primero un frame o prueba corta si hay incertidumbre visual. |
