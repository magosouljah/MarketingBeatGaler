# Módulo 3 — Selección y guiones V1.3

**Prioridad:** que el espectador tenga una razón concreta e importante para prestar atención, antes de exigir originalidad o variedad.

**Operación:** [GENERAR-V13.md](GENERAR-V13.md) → `python pipeline/ideacion.py comprobar inputs/<lote>.json` → [REVISAR-V13.md](../evaluacion/REVISAR-V13.md) en contexto independiente → solo entonces guiones.

1. **Explorar libremente** situaciones del productor desde la investigación. No hay cuotas de 15–20 ideas ni de cinco territorios.
2. **Profundizar** las que tengan relevancia potencial: deseo del productor, consecuencia importante, estímulo visible o audible, explicación causal («¿por qué?»), desarrollo que cumple la promesa y una objeción seria.
3. **Descartar con libertad:** un concepto diferente, gracioso o vistoso puede ser trivial. Permitir **0–3 finalistas**, incluso todos del mismo tema. Ninguno es un resultado válido si está justificado; no producir tres guiones de relleno.
4. **Revisión separada:** primero descartar por debilidad del interés y del razonamiento; después comprobar novedad, veracidad y relación comercial. No copiar ejemplos históricos.
5. **Guiones:** redactar solo las ideas aprobadas para desarrollo; antes de producción, el propietario debe aprobar. No confundir creatividad con retención comprobada.

**BeatGaler:** presencia `ninguna/discreta/indirecta/directa`; una pieza puede ser entretenimiento o utilidad sin venta, o un anuncio completo. No forzar funciones del producto ni anunciar capacidades no comprobadas como disponibles.

**Contratos históricos intactos:** `hipotesis.csv` conserva predicción y refutación; `guiones.csv` conserva aprobación explícita; `experimentos.csv` sirve para contrastes controlados. Los archivos G-001/G-002 y X-001 están descartados, **no** son semillas. Para nuevos guiones seleccionados, crear o reutilizar mecanismos **reales y trazables** en el módulo 2 antes de registrar hipótesis y guiones.

La comprobación automática no puede medir atención, calidad creativa ni similitud semántica. Los resultados publicados, cuando sean comparables, pesan más para inferir eficacia que la opinión estética; el propietario sigue decidiendo qué producir.
